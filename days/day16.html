Working with JSON and SQL

Load structured data into pandas from files, URLs, and databases.

JSON Basics

JSON is a universal data structure for sharing data.

You see it in APIs, configuration files, and many datasets on the web.

In pandas, the main entry point is pd.read_json.

158

read_json from File

Start by importing pandas:

import pandas as pd

Load JSON from a local file:

df = pd.read_json("file_name.json")
df.head()
159

read_json from URL

You can load JSON directly from a URL too:

import pandas as pd

url = "https://example.com/data.json"
df = pd.read_json(url)
df.head()

This is common when a dataset is hosted on GitHub or a public endpoint.

160

Read SQL into pandas

SQL is used to store and query data in databases.

One common setup is MySQL. In a notebook, you can install the connector like this:

!pip install mysql-connector-python

Create a connection:

import mysql.connector
import pandas as pd

conn = mysql.connector.connect(
    host="localhost",
    user="root",
    password="",
    database="world",
)

Then run a query and load the result into a DataFrame:

df = pd.read_sql_query("SELECT * FROM city", conn)
df.head()

Day 16 takeaways

  • JSON is a common format for sharing structured data.
  • pd.read_json loads JSON from a file or a URL.
  • SQL lets you query a database, then bring results into pandas.
  • pd.read_sql_query turns a SQL result into a DataFrame.
