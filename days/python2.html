What Is a String

A string is a data type. It stores a sequence of characters.

That sequence can be a word, a sentence, or a whole paragraph.

Word

A short string such as hello.

Sentence

A line of text such as this is a string.

Paragraph

Many sentences stored in one string.

Three Ways to Write Strings

Python gives you three quote styles. Use them so quotes inside the text do not confuse Python.

Input

str1 = "this is a string"
str2 = 'single word'
str3 = '''this is a program'''
print(str1)
print(str2)
print(str3)

Output

this is a string
single word
this is a program

This line fails. The inner quotes close the string too soon.

Input

print('this is a 'python' program')

Output

SyntaxError: invalid syntax

Fix it by wrapping the outer string in the other quote style.

Input

print("this is a 'python' program")

Output

this is a 'python' program

Escape Sequence Characters

An escape sequence is a short code inside a string that formats the text. The two you need today are a new line and a tab.

Write a backslash, then the letter. For a new line use \n. For a tab use \t.

Input

text = "this is a string \n this is a new line"
print(text)

Output

this is a string 
 this is a new line

Input

text = "this is a string \t this is a tab"
print(text)

Output

this is a string 	 this is a tab

The gap in the middle is a tab space.

Length

len() is a built in function. It counts the characters in a string, including spaces.

Input

c = "hello world"
length = len(c)
print(length)

Output

11

len() does not work with a plain number. Python shows an error.

Input

num = 12345678
print(len(num))

Output

TypeError: object of type 'int' has no len()

Indexing

When you make a string, every character gets an index. Indexing starts at 0. The index lets you read one character.

Look at the first characters of "this is a string". The blank cell is a space. Spaces count.

Each character has a number, starting at 0.

t h i s sp i s
0 1 2 3 4 5 6

Top row is the text. Bottom row is the index. sp means space.

Input

text = "this is a string"
print(text[0])
print(text[1])
print(text[2])
print(text[3])
print(text[4])
print(text[5])

Output

t
h
i
s
 
i

Index 4 prints a space, so that line looks empty.

You can read a character. You cannot change it. Strings do not allow that kind of modify.

Slicing

Slicing cuts a piece out of a string. This idea matters a lot later in machine learning, when you cut arrays and tables.

The start index is included. The end index is not included.

In text[0:5], Python keeps indexes 0, 1, 2, 3, and 4. It drops index 5.

Start is in. End is out.

text[0:5] on "this is a string".

t h i s sp i

Solid cells are kept. The ghost i at index 5 is not kept. The result is this plus a space.

Input

text = "this is a string"
print(text[0:5])
print(text[6:11])
print(text[5:len(text)])
print(text[5:])

Output

this 
s a s
is a string
is a string

text[5:] means from index 5 to the end. It matches text[5:len(text)].

Negative indexes count from the end. -1 is the last character. For "apple", app[-3:-1] keeps p and l. It does not keep e.

Input

app = "apple"
print(app[-3:-1])

Output

pl

String Functions

Python comes with built in string functions. They return a new value. They do not change the original string unless you save the result.

Function What it does
endswith("ing") True if the string ends with that piece. Else False.
capitalize() Makes the first character uppercase.
replace("this", "that") Puts the new piece in place of the old piece.
find("is") Index of the first time that piece appears.
count("is") How many times that piece appears.

Input

text = "this is a string"
print(text.endswith("ing"))
print(text.capitalize())
print(text.replace("this", "that"))
print(text.find("is"))
print(text.count("is"))

Output

True
This is a string
that is a string
2
2

find("is") is 2 because the first is sits inside this, at indexes 2 and 3.

If Elif Else

A conditional statement lets the program choose a path. You can use if, elif, and else.

Python uses indentation. That means extra space at the start of the line. The indented lines belong to that condition. This spacing is required.

One path is chosen

  1. if If this condition is True, run these lines.
  2. elif Else if the next condition is True, run these lines.
  3. else If none of the conditions were True, run these lines.

Input

age = 21

if (age > 18):
    print("you are an adult")
    print("can drive")
elif (age > 13):
    print("you are a teenager")
else:
    print("you are a child")

Output

you are an adult
can drive

Traffic Light

Here is the same idea with a traffic light. Match the color, then print the action. Use an else for any value that is not green, yellow, or red.

Input

light = "red"

if (light == "green"):
    print("you can drive")
elif (light == "yellow"):
    print("you can drive but be careful")
elif (light == "red"):
    print("you cannot drive")
else:
    print("invalid light")

Output

you cannot drive

If vs Elif

elif can only follow an if. You cannot start with elif.

An if is always checked. An elif is checked only when the if above it was False.

Two separate if blocks are both checked. They are not a chain.

Input

a = 10
if (a > 5):
    print("a is greater than 5")
if (a < 5):
    print("a is less than 5")

Output

a is greater than 5

Nesting

Nesting means an if statement inside another if statement. The inner check runs only when the outer check is True.

If inside if

  1. age > 18 First ask if the person is an adult.
  2. age > 30 Only then ask if they are older than 30.
  3. Print Print the matching line.

Input

age = 20
if (age > 18):
    if (age > 30):
        print("you are an adult and you are old")
    else:
        print("you are an adult and you are not old")
else:
    print("you are not an adult")

Output

you are an adult and you are not old

Python 2 takeaways

Python 2 takeaways

  • A string stores a sequence of characters. Use the quote style that keeps inner quotes safe.
  • Escape sequences format text. \n is a new line. \t is a tab.
  • Add strings with +. Count characters with len(). It does not work on a plain number.
  • Indexing starts at 0. You can read a character. You cannot change it.
  • Slicing cuts a piece. The start is included. The end is not.
  • Learn endswith, capitalize, replace, find, and count.
  • if, elif, and else choose a path. Indentation is required.
  • An if is always checked. An elif needs an if first. Nesting is an if inside an if.
