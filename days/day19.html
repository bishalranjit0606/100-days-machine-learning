Day 19

Understanding Your Data

Last chapter of Phase 1. Ask the right questions before you build. Gen AI starts on Day 20.

308

Questions After Loading Data

After you get a dataset, do not jump straight into modeling. Ask basic questions first.

Load the file and keep a simple checklist:

import pandas as pd

df = pd.read_csv("train.csv")
  • How big is the data?
  • How does the data look?
  • What are the column data types?
  • Are there missing values?
  • What do the numbers look like mathematically?
  • Are there duplicate rows?
  • How do columns relate to each other?

The next lessons answer each question with one pandas method.

309

How Big Is the Data

Question 1: How big is the data?

df.shape

shape gives two numbers: rows and columns.

Example output: (1000, 12) means 1000 rows and 12 columns.

Size tells you if the file is small enough to explore in memory, or if you need chunking later.

310

How Does the Data Look

Question 2: How does the data look?

See the first few rows:

df.head()

head() shows the top 5 rows by default.

Or sample random rows to avoid bias from the top of the file:

df.sample(5)

This gives 5 random rows so you see different parts of the dataset.

311

Column Data Types

Question 3: What is the data type of each column?

df.info()

info() shows column names, data types, and non null counts.

It also shows how much memory the DataFrame is using.

Check this early. A number stored as text, or a category stored as float, can break later steps.

312

Missing Values

Question 4: Are there any missing values? This is very important.

df.isnull().sum()

This counts missing values in each column.

After you know where gaps are, you can either fill them or remove the column. Do not ignore missing data and train a model on broken rows.

313

Math Summary with describe

Question 5: How does the numeric data look mathematically?

df.describe()

describe() gives count, mean, standard deviation, min, max, and quartiles like 25%, 50%, and 75%.

Use this to spot odd ranges, very large values, or columns that look flat and unhelpful.

314

Duplicate Values

Question 6: Are there duplicate rows?

df.duplicated().sum()

This counts how many rows repeat exactly.

Duplicates can inflate scores and mislead your model. Remove or fix them before training.

315

Correlation Between Columns

Question 7: How are columns related to each other?

Correlation means when one value goes up or down, another column may move in a linked way.

See the full correlation matrix:

df.corr()

Pick one column and read its links to others:

df.corr()["column_name"]

Values range from negative 1 to positive 1. Values close to 0 mean weak link. Values near 1 or negative 1 mean stronger link.

Use this to drop columns that repeat the same signal, or to spot features that may matter for your target.

Day 19 takeaways

  • Always explore data before modeling.
  • shape, head(), and sample() show size and samples.
  • info() shows types and memory use.
  • isnull().sum() finds missing values you must handle.
  • describe(), duplicated(), and corr() complete your first data check.

Run this checklist on every new dataset. Clean understanding here saves hours later.
