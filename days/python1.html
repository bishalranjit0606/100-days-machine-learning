What Is Python

Python is a programming language. You write instructions. The computer follows them.

It is a high level language. You write in words close to English. You do not talk to the machine in raw bits.

Programming language

A set of rules for writing instructions a computer can run.

High level

The code is readable for people. Python handles the hard machine details.

Python Character Set

A character set is every symbol Python is allowed to see in your code. In practice, that is letters, digits, symbols, spaces, and other ASCII characters.

Letters

a to z, and A to Z.

Digits

0 to 9.

Special symbols

Symbols such as +, -, and *.

Whitespace

A blank space, a tab, and a new line.

Other characters

ASCII covers the rest of the common keyboard characters.

Variables

A variable is a memory location in a program. You give that place a name. You store a value there.

Think of a shape whose sides are a and b. The area is a * b. You can change a and b. Those changing values are variables.

If you store "Bishal" in name, Python reserves that place in memory for that value.

Three names, three memory slots.

name = "Bishal", age = 24, price = 44.44.

Bishal
24
44.44

Left cell is name. Middle cell is age. Right cell is price.

To show what is inside name, you write print(name) with no quotes around the variable name. If you later change name, the new value is what prints.

Strings Integers and Floats

name = "Bishal" is a string. A string is a word or a mix of words. You can wrap it in single quotes, double quotes, or triple quotes.

age = 24 is an integer. That is a whole number.

price = 44.44 is a float. That is a number with a decimal.

Input

name = "Bishal"
age = 24
price = 44.44

print(name)
print(age)
print(price)
print("my name is ", name)

Output

Bishal
24
44.44
my name is  Bishal

Assignment

In age = 24, Python takes the value on the right and stores it in the name on the left.

You can copy that value into a second name. After age2 = age, both age and age2 hold 24.

Right value moves left

  1. 24 This is the value on the right.
  2. age The value is stored in age.
  3. age2 age2 = age copies 24 into age2.

Input

age = 24
age2 = age
print(age)
print(age2)

Output

24
24

Rules for Identifiers

An identifier is a name you choose, such as a variable name. Keep names simple and short.

A name can use letters a to z, digits 0 to 9, and underscore. It can be any length. It cannot use symbols such as %, #, or @. It cannot start with a digit.

Allowed Not allowed
name %name
age2 2age
my_price my@price

Data Types

A data type is the kind of value in a variable. You do not write the type. Python finds it from the value. print(type(age)) shows that type.

There are five types to learn today.

Integer

A whole number. Positive, negative, or 0.

String

A word or a sentence. Single quotes, double quotes, or triple quotes.

Float

A number with a decimal, such as 44.44.

Boolean

True or False. The T and the F must be capital.

None

No value. Write None with a capital N.

Input

age = 24
old = False
a = None

print(type(age))
print(type(old))
print(type(a))

Output

<class 'int'>
<class 'bool'>
<class 'NoneType'>

Comments

A comment never runs. Python skips it. Use comments to leave notes for yourself.

A one line comment starts with #. A multi line comment uses triple quotes. In many editors on a Mac, you can also press Command and the forward slash key to comment a line.

Input

# hello
print("this line runs")

"""
this is a multi line comment
Python does not run it
"""

Output

this line runs

Type Conversion and Casting

There are two ways a type can change.

Kind Who does it
Type conversion Python does it by itself.
Type casting You do it by hand with int(), float(), or str().

If you add an integer and a float, Python turns the integer into a float. Float can hold the decimal, so it wins.

Input

a = 2
b = 2.5
print(a + b)

Output

4.5

A string plus a number fails. Python will not guess for you.

Input

a = "2"
b = 2.5
print(a + b)

Output

TypeError: can only concatenate str (not "float") to str

Casting forces a new type when the value makes sense. int("2") works. int("hello") does not. You can also turn a number into a string with str().

Input

a, b = 2.51, "2"
c = int(b)
print(c)

n = 44
print(str(n))

Output

2
44

How to Take Input

input() asks the user to type something. What comes back is always a string, even if the person types a number.

If you need an integer or a float, cast it.

Input

name = input("what is your name: ")
print("welcome", name)

Output

what is your name: Bishal
welcome Bishal

The line after the colon is what the user typed.

Input

text = int(input("what: "))
print(type(text))

text = float(input("what: "))
print(type(text))

Output

what: 7
<class 'int'>
what: 7.5
<class 'float'>

Python 1 takeaways

Python 1 takeaways

  • Python is a high level programming language.
  • print is a function. It shows output in the terminal.
  • A variable is a named place in memory.
  • The five types today are integer, string, float, boolean, and None.
  • Python finds the type for you. It is case sensitive.
  • Keywords cannot be variable names. Comments never run.
  • Learn arithmetic, relational, assignment, and logical operators.
  • Python can convert types. Casting is when you change the type by hand.
  • input always returns a string. Cast it when you need a number.
