What Is Agentic AI

Agentic AI is a type of AI that takes a goal from a user and works to complete it with no human interface, or with only a small amount of it.

That is completely different from Gen AI that is a chatbot. A chatbot is reactive. Agentic AI does the work once we give the goal.

The table below puts those two side by side.

Gen AI chatbot Agentic AI
Reactive. It waits for the next prompt. Takes the goal and works to finish it.
You guide it step by step. Little or no human interface after the goal.

Six Characteristics

Agentic AI has six key characteristics. The cards below are that set. We open each one in the next lessons.

Autonomous

Takes action without a step by step script from you.

Goal oriented

Every move aims at the goal, not a random path.

Planning

Plan first, then execute, in a loop until the goal is done.

Reasoning

Draws conclusions from feedback and then decides.

Adaptability

Changes the plan when something unexpected happens.

Context aware

Keeps what matters from the past and the present.

630

Autonomous

Autonomy is the biggest characteristic. An agent is always autonomous. It takes action without a step by step explanation from you. It is proactive. It can run steps on its own, make decisions, and pick when to use which tool.

We can still control how much autonomy the agent has. The four cards below are those controls. Autonomy can be dangerous, so it needs to be controlled.

Permission scope

Limit what the agent is allowed to do.

Human in the loop

A checkpoint where a human must approve before it continues.

Override controls

A user can stop, pause, or change the agent behavior when they want.

Guardrails

Hard rules or ethical boundaries the agent must follow. Also called policies.

631

Goal Oriented

The agent tries to achieve the goal. It does not take random actions. The main aim is always to fulfill the goal.

Goals can come with constraints. You might say you want to hire only remote workers. You might say only 100 dollars in marketing is allowed to hire the candidate. Goals are stored in core memory. Goals can be altered.

632

Planning

Planning is the most important characteristic of an agentic system. First the agent plans, then it executes. That is a loop. It keeps working until the goal is achieved. It breaks a high level goal into a structured sequence of actions, also called subgoals.

The three steps below are how a plan is chosen.

Choose a plan, then run it

  1. Many plans The agent does not make one plan. It makes multiple plans, then looks for the most optimized one.
  2. Evaluate Check which plan is effective. Look at tool availability, cost, risk, and alignment.
  3. Select Pick the best plan with human in the loop input, or with a pre programmed policy.
633

Reasoning

Agents can reason. If we give feedback, they draw a conclusion and make a decision. Reasoning happens during planning and during execution. The table below splits those two times.

During planning During execution
Goal decomposition. Break the goal into steps. Decision making.
Tool selection. Human in the loop handling.
Resource estimate. Time, dependencies, and risk. Error handling.
634

Adaptability

Adaptability is the ability to modify plans, strategies, or actions when conditions are unexpected. The agent still stays with the goal.

A tool can fail. If the calendar is not working, the agent can message you and ask about a free date. If the goal itself changes, the agent also needs to adapt.

635

Context Awareness

Context awareness means the agent retains information from the past and the present. It keeps context such as progress till now, the environment state, tool responses, user specific preferences, and policy guardrails.

There are two types of memory. The cards below are those two.

Short term memory

What is in play right now, from the recent past.

Long term memory

What should last, such as the goal.

636

Five Components

An agentic system has five parts: brain, orchestrator, tools, memory, and supervisor. The cards below are that set.

Brain

Mostly an LLM based agent. The LLM is the brain. It interprets the goal, plans, reasons, selects tools, and communicates.

Orchestrator

How the task is executed. We often build this with LangGraph. Sequential tasks, conditional routing, looping, and retry logic. This part is like a manager that manages everything.

Tools

Connectors that help the agent reach other systems. They can come from an API, a webhook, or MCP.

Memory

Short term memory holds recent messages and tool calls. Long term memory holds things like the goal.

Supervisor

Asks a human for anything very important. Handles approval, human in the loop, and guardrails enforcement.

Day 47 takeaways

Day 47 takeaways

  • Agentic AI takes a goal and works to complete it with little or no human interface. A Gen AI chatbot is reactive.
  • The six characteristics are autonomous, goal oriented, planning, reasoning, adaptability, and context awareness.
  • Autonomy is the biggest trait. Control it with permission scope, human in the loop, override controls, and guardrails. Autonomy can be dangerous.
  • Goals can have constraints, such as remote only or a 100 dollar marketing limit. Goals live in core memory and can be altered.
  • Planning comes first. The agent makes multiple plans, evaluates them, then selects one with a human or a policy. It loops until the goal is done.
  • Reasoning during planning covers goal decomposition, tool selection, and resource estimates. During execution it covers decisions, human in the loop, and errors.
  • Adaptability changes the plan when a tool fails or the goal changes, and still stays with the goal.
  • Context includes progress, environment state, tool responses, user preferences, and guardrails. Memory is short term and long term.
  • The five parts are brain, orchestrator, tools, memory, and supervisor.
