Anaconda and Jupyter

Anaconda is a great choice for data science right now. It comes with most data science packages already installed.

Inside Anaconda you can use Jupyter Notebook.

In Jupyter you can:

  • Run Python code cell by cell.
  • Write markdown notes between code.
  • Use interactive widgets like buttons and forms.

This mix of code and notes is why Jupyter is popular for learning and experiments.

78

Datasets and Pandas

99% of the time we get datasets from Kaggle.

To load a CSV file into Jupyter, use pandas:

import pandas as pd

df = pd.read_csv("filename.csv")
df.head()

read_csv reads the file into a table called a DataFrame. head() shows the first few rows so you can check the data quickly.

79

Virtual Environments

When you start Jupyter, it often uses a default environment with many packages.

A virtual environment lets you create a fresh space and install only what you need.

From the command line with Anaconda:

conda create --name test
conda activate test
conda install -c anaconda jupyter
conda deactivate

Jupyter Notebook itself is also a library you install inside the environment.

Use a new env when a project needs specific package versions and you do not want to break other projects.

80

Kaggle and Google Colab

For beginners, you do not need to install everything on your laptop right away. Start with Kaggle or Google Colab.

Using Kaggle:

  • Create a free account at kaggle.com.
  • Search for a dataset or notebook.
  • Open a notebook in the browser and run code online.

Using Google Colab:

  • Go to colab.research.google.com.
  • Create a new notebook.
  • Run Python in the cloud with no local install.

Day 12 takeaways

  • Anaconda bundles data science tools. Jupyter mixes code and notes in one place.
  • Use pandas and read_csv to load CSV files. Kaggle is the main source for datasets.
  • Virtual envs keep projects clean. Beginners can start on Kaggle or Colab without setup stress.

Pick local Anaconda when you want full control. Pick Colab or Kaggle when you want to start fast.
