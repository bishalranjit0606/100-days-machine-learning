Hands on with Google ADK

This is a hands on session in Google Agent Development Kit, or ADK. ADK is a framework from Google for building agents you can run as real workflows.

We work in two parts. First, the foundation: what Gen AI is, and what agentic AI is. Then we set up ADK on your machine.

Here is what we will build today. Two agents, same idea: help a person show their work more clearly.

Resume agent

Takes a resume and a job description, then writes a new resume that fits the job.

LinkedIn reviewer

Reviews a LinkedIn profile and suggests clearer, stronger copy.

534

What Is Gen AI

Gen AI means generative AI. It creates new content. That content can be text, audio, images, and more.

You send it a message. It generates a reply. On its own, a plain Gen AI chat has no memory of past steps, and it does not call your functions.

535

How Gen AI Works

The basic path is short. You write a prompt. The model runs. You get output.

One pass

  1. Prompt You send a message.
  2. Model The Gen AI model reads it and generates.
  3. Output You get text, audio, an image, or similar content.

That is one shot. Receive a message. Generate a reply. Stop.

536

Gen AI vs an AI Agent

An agent is not just a better chatbot. The input is a goal, not only a message. Compare the two side by side.

Piece Gen AI AI agent
You give it A message. A goal.
It does Generate a reply. Decide what steps are needed to reach the goal.
Tools None on its own. Calls tools. Those are real functions that gather information or take action.
Next step Stops after the reply. No memory of a process. Looks at the tool result, then decides what to do next.
537

What Is an AI Agent

An AI agent is a system built on top of a Gen AI model. You give it a goal. It decides the actions.

Watch the loop. The model still generates language. The agent wraps that model with a plan, tools, and a next step.

Goal to action

  1. Goal Receive what you want done, not only a chat line.
  2. Plan Decide what steps are needed.
  3. Call tools Run real functions to gather facts or take action.
  4. Next Read the tool result. Decide the next step. Repeat until the goal is done.
538

Why ADK

When people first make agentic AI, they often use Claude or ChatGPT. They give the model an API, then let it work.

That can run a demo. It does not give you a defined process. Production work needs a clear workflow: the model, the instructions, the tools, memory, and a way to run it.

ADK is the framework that helps you make those production level workflows. That is the main reason we use it here.

What You Need

These four things are the base for ADK. Check them before you install anything.

Python 3.10 or newer

ADK needs a recent Python. 3.10 or above.

A terminal

The app where you type commands, such as Terminal on a Mac.

pip

The tool that installs Python packages.

A Google account

ADK talks to Gemini. You sign in with Google and use an API key from Google AI Studio.

540

Virtual Environment

A virtual environment is an isolated folder. It holds its own copy of Python and the packages you install for this project.

That keeps google-adk off your system Python. Other projects stay clean.

First create a folder, then create the environment inside it. The command is python3 -m venv .venv. The word is venv, short for virtual environment. The folder name .venv is the usual choice.

541

Install ADK with pip

Open a terminal. Move into your project folder. Create the environment, turn it on, then install ADK with pip.

Create, activate, install

cd google_adk
python3 -m venv .venv
source .venv/bin/activate
pip install google-adk

What you should see

(.venv) in front of your prompt after activate.
pip downloads google-adk and its dependencies.
When it finishes, the adk command is ready in this environment.

These activate steps are for Mac and Linux. For more detail, use the Python quickstart at adk.dev/get-started/python/.

543

Core Building Blocks of ADK

ADK is built from a few named pieces. Learn these names. You will see them in every agent you write.

Model

The Gen AI model, such as Gemini. It does the language work.

Instruction

The written job for the agent. What it should do, and how.

Tool

A real Python function the agent can call to gather information or take action.

Session

The running conversation. It holds context so the agent is not blank each turn.

Runner

The piece that runs the agent. It sends the goal, gets tool calls, and continues the loop.

544

Run with adk api_server

When the agent code is in place, you run it with the ADK API server. This command starts a local server so you can send requests to your agent.

Start the API server

adk api_server

What this does

Starts a local ADK API server.
You can create a session and send a goal to the agent.
Default address is http://localhost:8000.

Run this from the folder that contains your agent project. Keep the virtual environment active.

ADK takeaways
