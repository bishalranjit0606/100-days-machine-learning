Data Analyst, Engineer, Scientist, and ML Engineer

Why Four Job Profiles

There are 4 main job profiles in the data and ML world. Why four? The answer links back to MDLC.

MDLC has 9 steps. It is too large for one person to do everything alone. Teams split the work.

Each role owns part of the life cycle. Together they build the full product.

Data Engineer

A data engineer brings all the data needed to build ML models.

Big companies use OLTP (online transaction processing). Example: Flipkart. From OLTP we get OLAP (online analytical processing).

  • OLTP: actual running data in the database.
  • OLAP: data for analysis, often called a data warehouse.

Main tasks:

  • Scrape or collect data from given sources.
  • Move and store data in OLAP, secure servers, or warehouse.
  • Build data pipelines and APIs for easy access.
  • Handle database and data warehouse.

This is the most important role when data is large scale. Data is gold.

Skills: software development, databases, data structures and algorithms, programming languages, RDBMS, big data tools, cloud platforms (AWS, GCP), distributed systems, and data pipelines.

It is very difficult. This is hardcore software work.

66

Data Analyst

In MDLC, early steps like data gathering happen with help from the data engineer. The analyst then cleans and organizes the data.

Main work:

  • Summarize past data. Example: why did a product fail in the business?
  • Create data visualization.
  • Produce and maintain reports.
  • Collaborate with teams based on insight.
  • Optimize data collection procedures.

Data analyst and business analyst are almost similar. The tools are different.

Skills: statistical programming, programming languages, creative and analytical thinking, strong communication, data mining and cleaning, data visualization, data storytelling, SQL, advanced Microsoft Excel.

You also need domain skills. Example: if you work in the medical field, know the medical domain.

67

Data Scientist

A classic line: better at statistics than any software engineer, and better at software engineering than any statistician.

The data scientist can do almost every step in MDLC.

  • Data analyst looks at the past and gives a summary.
  • Data scientist works for the future.
  • Builds recommendations from point A to point B.

The ultimate goal for many learners is to become a data scientist. It is also called ML fullstack.

You need communication skills and to be very good at maths.

68

ML Engineer

Once the model is ready, the ML engineer deploys it.

Main work:

  • Scaling and optimizing the model for production.
  • Monitoring the model in production.
  • Keeping the model healthy over time.

Skills: mathematics, programming languages, distributed systems, data, model, and evaluation, software engineering, and system design.

Day 10 takeaways

  • MDLC is too big for one person. Four roles split the work.
  • Data engineer builds pipelines. Analyst explains the past. Scientist predicts the future. ML engineer ships to production.
  • Data scientist sits at the center of MDLC. ML engineer owns deployment and scale.

Pick a role that matches your skills today, then grow toward the full life cycle.
