Generative AI using LangChain

Build LLM apps with chains, RAG, and agents. Start on the user side path from Day 20.

256

What Is LangChain

LangChain is an open source framework for building applications on top of large language models.

If your app needs an LLM at the center, LangChain gives you structure instead of wiring everything by hand.

It is free, open source, and supports major Gen AI use cases.

LangChain simplifies LLM app development with integrations and wrappers that connect to many services.

257

What You Can Build

With LangChain you can build complex AI products, for example:

  • Chatbots.
  • Question and answer systems.
  • RAG apps that answer from your own documents.
  • AI agents that take actions for you.

LangChain supports all major LLMs. That broad support is one of its most important features.

258

Why LangChain First

From Day 20 you learned the user perspective path for Gen AI.

LangChain is a strong first framework on that path because one codebase can talk to many model providers.

You can work with:

  • Open source models.
  • Closed source models.
  • LLM APIs.
  • Hugging Face.
  • Llama and more.

Learn LangChain once. Swap models later without rewriting the whole app.

259

Three Parts of LangChain

Think of LangChain in three layers:

  1. LangChain fundamentals. This is the most important part. Chains, prompts, models, and tools.
  2. RAG applications. Bring your own data into the LLM safely.
  3. AI agents. Let the LLM plan steps and use tools.

Master fundamentals first. RAG and agents build on the same ideas.

260

Integrations and Wrappers

LangChain gives you integrations for common services.

A wrapper is a small adapter that lets your app call a service with a consistent interface.

That means you can plug in vector databases, document loaders, LLM APIs, and tools without custom glue code for every provider.

This is why LangChain feels like a complete ecosystem, not just a single library call.

261

Chains and Benefits

LangChain is built around chains: steps linked in a pipeline.

Main benefits:

  • Chains: clear pipeline from input to output.
  • Modular: parts are easy to reuse, remove, or add.
  • Ecosystem: loaders, retrievers, tools, and memory in one place.
  • Memory: keep conversation context across turns in chat apps.

When one step changes, you often swap one link, not the whole project.

263

Embeddings and Vectors

Embedding means turning text into a vector: a list of numbers that capture meaning.

You embed the whole document (in chunks) and you also embed the user query.

Similar meaning tends to land close together in vector space. That is how semantic search works.

Embeddings are the bridge between plain language and a database that can search by meaning, not only exact keywords.

264

Chunking Documents

Before embedding a PDF or long file, you usually chunk it into smaller pieces.

Chunking can be based on:

  • Pages.
  • Paragraphs.
  • Chapters.
  • Custom rules for your data.

Good chunk size matters. Too large and retrieval is vague. Too small and context is lost.

LangChain includes document loaders and text splitters to handle this step.

265

RAG Flow Step by Step

RAG means retrieval augmented generation. Here is the flow in plain steps.

Offline (prepare data):

  • PDF or docs go in.
  • Text is chunked.
  • Chunks become embeddings.
  • Vectors are stored in a database.

Online (answer a question):

  • User query becomes an embedding.
  • Semantic search finds the best matching chunks.
  • System prompt combines retrieved pages plus the user question.
  • The LLM returns the final answer.
266

Swapping LLM Providers

Real projects change. You might start with one API and move to another, for example Gemini instead of ChatGPT.

LangChain helps you handle these moving parts.

The chain structure stays similar. You swap the model wrapper or integration.

That saves time when pricing, speed, or policy pushes you to a new provider.

267

Alternatives and Takeaways

LangChain is popular, but not the only option.

  • LlamaIndex: strong focus on data indexing and RAG.
  • Haystack: search and QA pipelines, often for production search.

Many teams still start with LangChain for breadth, then specialize if needed.

Day 21 takeaways

  • LangChain is an open source framework for LLM based apps.
  • Learn fundamentals, then RAG, then agents.
  • Embeddings plus chunking plus retrieval power document Q and A.
  • Chains, memory, and wrappers make apps modular.
  • You can swap LLM providers without rebuilding from scratch.
