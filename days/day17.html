Fetching Data from an API

What Is an API

API means application programming interface.

Simple meaning: an API helps two software systems talk to each other.

In many projects, an API becomes your data pipeline. Your app asks for data, and the API sends it back.

256

TMDB API to DataFrame

We can practice with a movie API like TMDB. You can create an API key at developers.themoviedb.org.

Make a request and read the JSON response:

import pandas as pd
import requests

response = requests.get("YOUR_API_URL_HERE")
data = response.json()
results = data["results"]

Create a DataFrame and pick only the columns you care about:

df = pd.DataFrame(results)
df.head(2)[["id", "popularity", "vote_count", "vote_average"]]

Collect Many Pages

APIs often return one page at a time. You then loop through pages and combine the results.

A clean pattern is to collect small DataFrames in a list, then merge them once:

import pandas as pd
import requests

all_pages = []

for page in range(1, 429):
    response = requests.get("YOUR_API_URL_HERE", params={"page": page})
    results = response.json()["results"]
    all_pages.append(pd.DataFrame(results))

df = pd.concat(all_pages, ignore_index=True)
df.head()

Day 17 takeaways

  • An API helps software systems exchange data.
  • Many APIs return JSON. You can load it with response.json().
  • Convert results into a DataFrame and select columns for analysis.
  • For many pages, loop and combine with pd.concat.
