What Pandas Is

Pandas is a Python library for working with structured data.

Structured data usually looks like a table with rows and columns.

You mainly use Pandas to:

  • Read datasets.
  • View and understand datasets.
  • Select rows and columns.
  • Filter data.
  • Sort data.
  • Add, edit, or remove data.
  • Clean incorrect or missing values.
  • Group and summarize data.
  • Combine multiple datasets.
  • Perform basic exploratory data analysis.
  • Export processed data.

You do not need to memorize every Pandas function.

You need to understand:

  • What your dataset contains.
  • What result you want.
  • Which rows or columns should be used.
  • What conditions should be applied.
  • How the result should be summarized or transformed.

Then you can explain the task clearly to an AI.

Index

The index is the label Pandas uses to identify each row.

By default, Pandas creates indexes starting from zero.

The index is not usually part of the actual dataset unless you intentionally make a column the index.

Pandas uses the index to locate, align, and identify rows.

You mostly use it when:

  • Selecting a particular row.
  • Resetting row numbers after filtering.
  • Using a meaningful unique value as a row identifier.
df = df.reset_index(drop=True)

Data Types

Common Pandas data types include:

  • int for whole numbers.
  • float for decimal numbers.
  • object or string for text.
  • bool for true or false.
  • datetime for dates and times.

Matching types matter. For example:

  • Salary should be numeric.
  • Name should be text.
  • Joining date should be datetime.
  • Active status should be boolean.

If types are wrong:

  • Calculations fail.
  • Dates are treated as text.
  • Numbers are stored as text.
  • Filtering produces unexpected results.
print(df.dtypes)

Missing Values

A missing value means data is unavailable. Pandas often shows these as NaN or None.

Missing values can break calculations, skew averages, hurt models, remove rows from analysis, or reveal collection problems.

df.isna().sum()

Removing missing values

Remove rows when the missing field is essential, only a few rows are affected, or filling would mislead.

clean_df = df.dropna(subset=["salary"])

Filling missing values

Common choices: median for many numeric columns, mode for categories, Unknown for text.

df["salary"] = df["salary"].fillna(df["salary"].median())
df["city"] = df["city"].fillna("Unknown")

Mean, median, or mode

  • Mean is the average. Use it when numeric data is balanced.
  • Median is the middle value after sorting. Use it when there are unusually high or low values.
  • Mode is the most common value. Use it for categories or repeated values.
salary_mean = df["salary"].mean()
salary_median = df["salary"].median()
city_mode = df["city"].mode()[0]

Cleaning Text

Standardizing text

Text standardization makes values consistent. Kathmandu, kathmandu, and KATHMANDU should usually become one value.

Pandas treats differently written values as different categories.

df["city"] = (
    df["city"]
    .str.strip()
    .str.title()
)

Changing case

Use lowercase for emails, uppercase for product codes, and title case for names when that matches your rules.

df["name"] = df["name"].str.title()

Splitting text columns

Split one text field into several columns when combined values are hard to analyze.

email_data = pd.DataFrame({
    "email": ["asha@example.com", "bikash@company.com"]
})
email_data[["username", "domain"]] = email_data["email"].str.split(
    "@",
    expand=True
)

Aggregation and Groupby

Aggregation

Aggregation reduces many values into a summary such as count, sum, mean, median, minimum, or maximum.

average_salary = df["salary"].mean()
highest_salary = df["salary"].max()

Grouping data

groupby divides data into categories and calculates a summary for each category.

result = (
    df.groupby("department")["salary"]
    .mean()
    .reset_index()
)

Multiple aggregations

summary = (
    df.groupby("department")
    .agg(
        employee_count=("name", "count"),
        average_salary=("salary", "mean"),
        maximum_salary=("salary", "max"),
        average_experience=("experience", "mean")
    )
    .reset_index()
)

Concat and Merge

Concatenating DataFrames

Concatenation places DataFrames above or beside each other. Most often you stack rows from similar files.

combined = pd.concat(
    [january_df, february_df],
    ignore_index=True
)

Merging DataFrames

Merging combines datasets using a shared column. It is like looking up related information from another table.

merged = pd.merge(
    employees_df,
    salaries_df,
    on="employee_id",
    how="left"
)

Merge types

  • Inner merge keeps only matching records.
  • Left merge keeps every record from the first DataFrame.
  • Right merge keeps every record from the second DataFrame.
  • Outer merge keeps every record from both DataFrames.

Use inner when only complete matches matter. Use left when your first table is the main dataset. Use outer when you want to detect missing matches from either side.

Pivot and Melt

Pivot tables

A pivot table summarizes values using rows and columns for compact business reports.

pivot = pd.pivot_table(
    df,
    values="salary",
    index="department",
    columns="city",
    aggfunc="mean"

Wide data to long data

Wide data stores similar measurements in separate columns. Long data stores the measurement type in one column and values in another.

Long format is often easier for grouping, charting, and machine learning preparation.

    value_vars=["January", "February"],
    var_name="month",

Basic EDA

EDA means exploratory data analysis. It is how you understand a dataset before conclusions or models.

EDA helps detect missing values, duplicate rows, incorrect data types, unusual values, category distributions, numeric relationships, and quality problems.

Use EDA before reporting, machine learning, dashboards, business decisions, and deep cleaning.

print(df.shape)
print(df.dtypes)
print(df.isna().sum())
print(df.duplicated().sum())
print(df.describe())

Descriptive statistics

Describe shows count, mean, standard deviation, minimum, maximum, quartiles, and median for numeric columns.

df[["age", "salary", "experience", "rating"]].describe()

Unique values

print(df["department"].unique())
print(df["department"].nunique())

Unusual values

Examples: negative salary, age of 250, rating above 5, experience greater than age.

invalid_ratings = df[
    (df["rating"] < 0) |
    (df["rating"] > 5)
]

Correlation

Correlation measures whether two numeric columns tend to change together. A value near zero means little linear relationship.

Correlation does not prove that one variable causes another.

correlation = df[
    ["age", "salary", "experience", "rating"]
].corr()
print(correlation)

Common Mistakes

Incorrect column name

Column names are case sensitive. df["Salary"] fails if the real name is salary.

print(df.columns.tolist())

Numbers stored as text

Values like "50000", "NPR 50,000", or "60k" can break math.

df["salary"] = (
    df["salary"]
    .astype(str)
    .str.replace(",", "", regex=False)
    .str.replace("NPR", "", regex=False)
    .str.strip()
)
df["salary"] = pd.to_numeric(df["salary"], errors="coerce")

Dates stored as text

Text dates may sort alphabetically instead of by time.

df["date"] = pd.to_datetime(df["date"], errors="coerce")

Missing parentheses in filters

Wrong:

df[df["department"] == "IT" & df["salary"] > 50000]

Correct:

df[
    (df["department"] == "IT") &
    (df["salary"] > 50000)
]

Using and instead of &

In Pandas filters use & and |, not Python and / or.

Changing the original by accident

Prefer a new variable when cleaning.

clean_df = df.dropna(subset=["salary"])

Merge creating extra rows

A merge can multiply rows when the merge key is duplicated.

print(employees_df["employee_id"].duplicated().sum())
print(salaries_df["employee_id"].duplicated().sum())

Practical Workflow

For most datasets, follow this order.

# 1 Load
df = pd.read_csv("data.csv")

# 2 Preview
df.head()

# 3 Inspect
print(df.shape)
df.info()

# 4 Check quality
print(df.isna().sum())
print(df.duplicated().sum())

# 5 Fix column names
df.columns = (
    df.columns
    .str.strip()
    .str.lower()
    .str.replace(" ", "_")
)

# 6 Fix data types
df["salary"] = pd.to_numeric(df["salary"], errors="coerce")

# 7 Clean missing values and duplicates
df = df.drop_duplicates()
df["salary"] = df["salary"].fillna(df["salary"].median())

# 8 Filter and transform
result = df[df["experience"] >= 3].copy()
result["annual_salary"] = result["salary"] * 12

# 9 Group or summarize
summary = (
    result.groupby("department")
    .agg(
        employee_count=("name", "count"),
        average_salary=("salary", "mean")
    )
    .reset_index()
)

# 10 Export
summary.to_csv("department_summary.csv", index=False)

Closing Checklist

You are ready to use Pandas effectively when you understand these ideas:

  • A DataFrame is a complete table.
  • A Series is one column.
  • Rows are records.
  • Columns are variables or fields.
  • The index identifies rows.
  • Data types control what operations are possible.
  • Filtering keeps rows that match conditions.
  • Selection keeps the columns you need.
  • Transformation creates or changes values.
  • Aggregation summarizes many rows.
  • Grouping calculates summaries for categories.
  • Merging connects related tables.
  • Missing values and duplicates must be checked.
  • EDA helps you understand data quality and patterns.
  • Exporting saves your final result.

You do not need to remember every function.

You need to be able to say:

  • Load this dataset.
  • Check its structure and data quality.
  • Convert these columns to the correct types.
  • Clean missing and duplicate records using these rules.
  • Filter rows using these conditions.
  • Create these calculated columns.
  • Group the data using this category.
  • Calculate these summary values.
  • Sort the result this way.
  • Export these columns to this file format.

That is the practical Pandas knowledge required to work effectively with an AI coding assistant.
