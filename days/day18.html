Day 18

Fetching Data from the Web

Scrape HTML pages with requests and BeautifulSoup, then build a pandas DataFrame.

258

What Is Web Scraping

Web scraping means reading a web page and pulling out the data you need.

Use it when there is no API, or when the data only lives on a public HTML page.

Today we scrape a company list page and store the results in pandas. Start with these imports:

import pandas as pd
import requests
from bs4 import BeautifulSoup
import numpy as np

requests downloads the page. BeautifulSoup helps you search the HTML. pandas stores the clean table. numpy helps fill missing values later.

259

Headers for 403 Errors

Some sites block plain requests and return status code 403.

Send a browser style header so the request looks normal:

headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 6.3; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/80.0.3987.162 Safari/537.36"
}

webpage = requests.get("url", headers=headers).text

If the page loads without a 403, you can skip the headers. Keep this pattern ready when a site blocks you.

260

Fetch and Parse HTML

Download page 1 of the company list:

webpage = requests.get("https://www.ambitionbox.com/list-of-companies?page=1").text

Parse the HTML with BeautifulSoup:

soup = BeautifulSoup(webpage, "lxml")

You can print a clean view with soup.prettify() while you explore tags.

Find the main heading:

soup.find_all("h1")[0].text

Example output: List of companies in India.

261

Find Company Names

Company names sit inside h2 tags. Loop through them and strip extra spaces:

for i in soup.find_all("h2"):
    print(i.text.strip())

You should see names like TCS, Accenture, ICICI Bank, Cognizant, and more.

Printing every p tag is less useful. Those tags mix ratings, locations, ages, and long descriptions. Next we target the fields we care about.

262

Ratings and Reviews

Ratings use a class named rating:

len(soup.find_all("p", class_="rating"))

Review counts use a class named review-count:

len(soup.find_all("a", class_="review-count"))

Both return 30 on this page. That matches one page of companies.

Each company card lives in a wrapper div:

company = soup.find_all("div", class_="company-content-wrapper")
len(company)

Again you get 30. Work card by card so name, rating, and reviews stay aligned.

263

One Page to DataFrame

Build empty lists, fill them from each company card, then make a DataFrame:

name = []
rating = []
reviews = []
ctype = []
hq = []
how_old = []
no_of_employee = []

for i in company:
    name.append(i.find("h2").text.strip())
    rating.append(i.find("p", class_="rating").text.strip())
    reviews.append(i.find("a", class_="review-count").text.strip())
    ctype.append(i.find_all("p", class_="infoEntity")[0].text.strip())
    hq.append(i.find_all("p", class_="infoEntity")[1].text.strip())
    how_old.append(i.find_all("p", class_="infoEntity")[2].text.strip())
    no_of_employee.append(i.find_all("p", class_="infoEntity")[3].text.strip())

df = pd.DataFrame({
    "name": name,
    "rating": rating,
    "reviews": reviews,
    "company_type": ctype,
    "Head_Quarters": hq,
    "Company_Age": how_old,
    "No_of_Employee": no_of_employee,
})

df.shape

Shape is (30, 7): 30 companies and 7 columns.

The infoEntity tags hold company type, headquarters, age, and employee count in order.

264

Scrape Many Pages

Loop through pages, scrape each page, and combine the tables. Use try and except so one missing field does not stop the whole run:

final_pages = []

for j in range(1, 1001):
    webpage = requests.get(
        "https://www.ambitionbox.com/list-of-companies?page={}".format(j)
    ).text
    soup = BeautifulSoup(webpage, "lxml")
    company = soup.find_all("div", class_="company-content-wrapper")

    name = []
    rating = []
    reviews = []
    ctype = []
    hq = []
    how_old = []
    no_of_employee = []

    for i in company:
        try:
            name.append(i.find("h2").text.strip())
        except Exception:
            name.append(np.nan)

        try:
            rating.append(i.find("p", class_="rating").text.strip())
        except Exception:
            rating.append(np.nan)

        try:
            reviews.append(i.find("a", class_="review-count").text.strip())
        except Exception:
            reviews.append(np.nan)

        try:
            ctype.append(i.find_all("p", class_="infoEntity")[0].text.strip())
        except Exception:
            ctype.append(np.nan)

        try:
            hq.append(i.find_all("p", class_="infoEntity")[1].text.strip())
        except Exception:
            hq.append(np.nan)

        try:
            how_old.append(i.find_all("p", class_="infoEntity")[2].text.strip())
        except Exception:
            how_old.append(np.nan)

        try:
            no_of_employee.append(i.find_all("p", class_="infoEntity")[3].text.strip())
        except Exception:
            no_of_employee.append(np.nan)

    df = pd.DataFrame({
        "name": name,
        "rating": rating,
        "reviews": reviews,
        "company_type": ctype,
        "Head_Quarters": hq,
        "Company_Age": how_old,
        "No_of_Employee": no_of_employee,
    })
    final_pages.append(df)

final = pd.concat(final_pages, ignore_index=True)
final.shape

One page has 30 rows. Across 1000 pages you can reach about (30000, 7).

Use pd.concat to stack page tables. Older notebooks used DataFrame.append, but that method is gone in current pandas.

Day 18 takeaways

  • Web scraping pulls data from HTML when no API is available.
  • Use requests to download a page and BeautifulSoup to search tags.
  • Send a User Agent header if the site returns 403.
  • Scrape one card at a time so fields stay aligned in your lists.
  • Loop pages, handle missing fields with try and except, then combine with pd.concat.

Respect site rules and rate limits. Scrape only public pages you are allowed to use.
