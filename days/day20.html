273

What Generative AI Is

Generative AI is a type of AI that creates new content such as text, music, video, and images.

It learns patterns from existing data. Then it mimics human creative work to make something new.

In short: older tools often predicted or classified. Gen AI can create.

274

Gen AI Changed Creative Work

Machine learning has long had many kinds of models, for example:

  • Prediction models like regression.
  • Classification problems.
  • Recommendation problems.

For a long time, ML was not strong on creative platforms. Gen AI changed that.

Creating text, images, music, and video is a big power of Gen AI.

People used to say AI cannot replace human creativity. Gen AI made that debate real again.

275

From AI to Gen AI

A simple path helps you place Gen AI in the stack:

AI → ML → DL → Gen AI

  • AI has many techniques. ML is the main one for most products.
  • ML has many techniques. Deep learning (DL) is used a lot.
  • DL has many techniques. Gen AI is the popular focus now.

So Gen AI sits on top of deep learning ideas, not outside AI.

This series follows the user path

Impact Areas

In about three years, Gen AI became very important. These are major impact areas.

1. Customer support

Chatbots try to solve the problem first. A human support person steps in only when the chatbot cannot finish the job.

2. Content creation

People make blogs, videos, and more with Gen AI. Content is one of the main places Gen AI has reached.

3. Education

Learners can have a personal tutor available any time.

4. Software development

Gen AI writes code and makes programming easier. That is another real impact.

Why Learning Gen AI Feels Hard

Some people ask: why not Gen AI yet?

  • The tech feels new.
  • It might be a bubble.
  • Gen AI keeps bringing a new term, a new tool, or a new paper.

That flood of new things feels overwhelming. Feeling lost is common. It does not mean you are behind forever.

280

Problems and Mental Models

Gen AI has clear problems for learners:

  • Very fast progress.
  • A lot of noise. FOMO merchants can make you feel demotivated.
  • No single source to learn everything.

Solution: build a mental model.

A mental model is a simple map in your head. It tells you where a new term belongs, so every new tool does not restart your learning from zero.

281

Foundation Models

The main idea to learn early is the foundation model.

A foundation model is an AI model trained on very large data.

Many models we build for products are task specific. They mainly do one job.

Foundation models are generalized. They have many parameters and much training data.

A top example of a foundation model is an LLM (large language model). An LLM can do many tasks, not only one narrow prediction.

282

LLMs and Multimodal Models

Foundation models do more than predict the next bit of text. They can chat, summarize, translate, write code, and more.

There are not only LLMs. There are also multimodal models (sometimes called LMMs).

Multimodal models work with more than one kind of input, for example text, sound, and images together.

So Gen AI is bigger than chatbots alone.

283

Build or Use

Gen AI has two big paths:

  • Make an LLM or foundation model.
  • Use an LLM or foundation model.

You can think from a user perspective or a builder perspective.

Once you hold that lens, the game gets clearer. Most new buzzwords fit one side or the other.

284

User vs Builder Terms

Any new term you hear is usually a user idea or a builder idea.

  • Prompt engineering: user perspective. Better prompts for better responses.
  • RLHF: builder perspective. It helps safeguard and steer the LLM.
  • RAG: user perspective. Give personal or private data to the LLM safely.
  • Pre training: builder perspective.
  • Quantization: builder perspective. Optimize the LLM so it can run in more environments.
  • AI agent: user perspective.
  • Vector database: user perspective.
  • Fine tuning: both user and builder perspectives.

Labeling each term this way cuts confusion fast.

285

Builder Learning Path

Prerequisite: PyTorch or TensorFlow.

  1. Transformer architecture. Learn how transformers work, including self attention.
  2. Types of transformers. Encoder only models like BERT. Decoder only models like GPT.
  3. Pre training. Training objectives, tokenization strategies, training strategies, challenges, and evaluation.
  4. Optimization. Training optimization, model compression, and inference optimization.
  5. Fine tuning. Task specific tuning, instruction tuning, and continual pre training.
  6. Evaluation. Measure quality and safety.
  7. Deployment. Ship the model into real use.

This path is closer to research and deep model work.

286

User Learning Path

  1. Build basic LLM apps. Use open source models, closed source models, LLM APIs, Hugging Face, Llama, and frameworks like LangChain.
  2. Improve the LLM for your case.
    • Prompt engineering for better responses.
    • RAG so the model can use your personal or company data.
    • Fine tuning at the user level when prompts and RAG are not enough.
  3. AI agents. Let the LLM do work for you, such as booking a ticket.
  4. LLM Ops. Deploy the application. Many libraries help here.
  5. Miscellaneous. Other Gen AI tools such as Stable Diffusion for images, and more.

This path is closer to product building with existing models.

287

Do You Need Both

Do you need builder and user paths?

  • Data scientist: often more builder level.
  • Software developer: often more user side.
  • Combination: AI engineer.

An AI engineer knows foundation model ideas from the builder side and can also ship work on the user side.

You do not need every paper. You need a clear map: build, use, or both for your role.

Day 20 takeaways

  • Gen AI creates new content by learning patterns from data.
  • It sits in the path AI to ML to DL to Gen AI.
  • Foundation models and LLMs are the core mental models.
  • Sort new terms by user vs builder to cut noise.
  • Pick a path for your role: builder, user, or AI engineer.

Start with the map. Then learn tools one step at a time.
