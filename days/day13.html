The Placement Project

Open Google Colab. Today we build a small end to end project: predict student placement from cgpa and iq.

If you skipped the NumPy or Pandas chapters above, go back and read them first. You need import numpy as np and import pandas as pd for this project.

Always start with these imports:

import numpy as np
import pandas as pd

Load the dataset from the web:

url = "https://raw.githubusercontent.com/campusx-official/placement-project-logistic-regression/main/placement.csv"
df = pd.read_csv(url)
df.head()

Or after uploading the file to Colab:

df = pd.read_csv("/content/placement.csv")
df.head()

This project walks through the MDLC steps we learned: preprocess, train, evaluate, and save.

Explore the Data

df.shape    # (100, 4) → 100 rows, 4 columns
df.info()

df.info() shows column names, data types, and missing values.

You will see: cgpa, iq, placement, plus an extra index column called Unnamed: 0.

Drop the useless index column:

df = df.iloc[:, 1:]
df.head()

Now we have 3 useful columns: cgpa, iq, placement.

Step 0: EDA

Step 0 is preprocess + EDA + feature selection.

Plot cgpa vs iq, colored by placement:

import matplotlib.pyplot as plt

plt.scatter(df["cgpa"], df["iq"], c=df["placement"])
plt.xlabel("cgpa")

This helps you see if placed and not placed students form different groups.

We keep cgpa and iq as input features. placement is the target we want to predict.

Six steps in this project.

  1. Step 0 Preprocess + EDA.
  2. Step 1 Extract X and y.
  3. Step 2 Scale values.
  4. Step 3 Train test split.
  5. Step 4 Train model.
  6. Step 5 Evaluate.
272

Input, Output, and Scaling

Step 1: split input and output.

X = df.iloc[:, 0:2]   # cgpa, iq
y = df.iloc[:, -1]    # placement

X is input. y is output.

Step 2: scale the values.

cgpa and iq sit on very different ranges. One column might be 4 to 10, another 40 to 200. That can confuse the model.

We scale so values sit in a similar range (often around -1 to 1). We do this after the train test split on the next step.

273

Train Test Split

Step 3: train test split. Also called part of cross validation.

We cannot test on the same data we trained on. That would be cheating.

So we hide some rows for testing. Example: 90 students for training, 10 for testing.

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.1)

We train on 90 rows. We check the model on the 10 hidden rows to see if it really works.

Then scale (Step 2 in code, right after split):

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

Fit the scaler on training data only. Then apply the same scale to test data.

274

Train and Evaluate

Step 4: train the model.

from sklearn.linear_model import LogisticRegression

clf = LogisticRegression()
clf.fit(X_train, y_train)

We use Logistic Regression because placement is yes/no (classification).

Step 5: evaluate the model.

y_pred = clf.predict(X_test)

from sklearn.metrics import accuracy_score
accuracy_score(y_test, y_pred)   # e.g. 0.9 means 90% correct

Sometimes we train multiple algorithms and pick the best one. That is model selection.

275

Save the Model

Step 6: save the trained model so you can use it later without retraining.

import pickle

pickle.dump(clf, open("model.pkl", "wb"))

This writes the model to a file. Later you can load it and make predictions on new students.

That is the start of deployment: train once, save, reuse.

Day 13 takeaways

  • End to end means load data, clean, explore, split, train, evaluate, and save.
  • Always split train and test. Never test on training data.
  • Scale features when ranges differ. Logistic Regression gave 90% accuracy on our test set.
