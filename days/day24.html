Temperature Recap

While learning models, we used parameters like temperature.

Temperature controls how creative the model is.

Example: ask it to write a poem with temperature set to 0. You get the same output every time for that same input.

If you raise the temperature, the output can change even when the input stays the same.

What Are Prompts

Prompts are the input instructions or query you give to a model to guide its output.

They tell the model what to do, how to answer, and what style or limits to follow.

Prompts matter so much that prompt engineering has become its own job profile.

233

Text Based and Multimodal Prompts

By content type, prompts fall into two groups:

  1. Text based prompts. Only text.
  2. Multimodal prompts. Text plus image, and sometimes sound or video as well.

Our main focus is text based prompts. About 99% of the time, that is what you will use.

234

Static and Dynamic Prompts

So far we often wrote a fixed string ourselves:

model.invoke("whats the capital of nepal")

That is a static style: the developer hard codes the prompt.

In the real world, a user types a prompt and clicks send. The LLM receives that text and returns a result. We as developers do not write every prompt by hand for each user.

That need for user driven text leads to dynamic prompts: a reusable template with slots filled at run time.

235

Why PromptTemplate Over f Strings

You can build dynamic text with Python f strings. That works for small demos.

Using PromptTemplate is a better habit:

  • You can turn on checks such as validate_template=True.
  • You can reuse the same template many times.
  • You can save a template to a file, for example template.json, and load it later.

f strings fill values right away. PromptTemplate keeps placeholders until you call invoke with a dict of values.

236

PromptTemplate Basics

Create a template with named slots, then fill them when you run.

from langchain_core.prompts import PromptTemplate

template = PromptTemplate(
    template="""Please summarize the research paper titled "{paper_input}"
with style {style_input} and length {length_input}.""",
    input_variables=["paper_input", "style_input", "length_input"],
)

# optional: keep the template on disk
template.save("template.json")

Later you pass a dict such as {"paper_input": "...", "style_input": "...", "length_input": "..."} into invoke.

237

Research Tool with PromptTemplate

Here is a Streamlit research summarizer. The user picks paper, style, and length. The template fills those slots, then the chain runs.

from langchain_groq import ChatGroq
from langchain_core.prompts import PromptTemplate
from dotenv import load_dotenv
import streamlit as st

load_dotenv()

model = ChatGroq(model="llama-3.3-70b-versatile")

st.header("Research Tool")

paper_input = st.selectbox(
    "Select Research Paper Name",
    [
        "Attention Is All You Need",
        "BERT: Pre-training of Deep Bidirectional Transformers",
        "GPT-3: Language Models are Few-Shot Learners",
        "Diffusion Models Beat GANs on Image Synthesis",
    ],
)

style_input = st.selectbox(
    "Select Explanation Style",
    ["Beginner-Friendly", "Technical", "Code-Oriented", "Mathematical"],
)

length_input = st.selectbox(
    "Select Explanation Length",
    ["Short (1-2 paragraphs)", "Medium (3-5 paragraphs)", "Long (detailed explanation)"],
)

template = PromptTemplate(
    template="""Please summarize the research paper titled "{paper_input}" with the following specifications:
Explanation Style: {style_input}
Explanation Length: {length_input}

1. Mathematical Details:
   - Include relevant mathematical equations if present in the paper.
   - Explain the mathematical concepts using simple, intuitive code snippets where applicable.

2. Analogies:
   - Use relatable analogies to simplify complex ideas.

If certain information is not available in the paper, respond with: "Insufficient information available" instead of guessing.
Ensure the summary is clear, accurate, and matches the requested style and length.
""",
    input_variables=["paper_input", "style_input", "length_input"],
)

if st.button("Summarize"):
    chain = template | model
    result = chain.invoke(
        {
            "paper_input": paper_input,
            "style_input": style_input,
            "length_input": length_input,
        }
    )
    st.write(result.content)

Notice chain = template | model. The pipe connects the filled prompt to the chat model in one step.

Chat Message Types

Chat models work with typed messages, not only plain strings.

  • SystemMessage: instructions for the assistant (role and rules).
  • HumanMessage: text from the user.
  • AIMessage: text from the model.
from langchain_core.messages import SystemMessage, HumanMessage, AIMessage

messages = [
    SystemMessage(content="You are a helpful assistant that can answer questions and help with tasks."),
    HumanMessage(content="What is the capital of France?"),
    AIMessage(content="The capital of France is Paris."),
]

result = model.invoke(messages)
messages.append(result)
print(messages)

Build a Chatbot Loop

Keep a list of messages. Each turn, append the human message, call the model with the full history, then append the AI reply.

from langchain_groq import ChatGroq
from dotenv import load_dotenv
from langchain_core.messages import SystemMessage, HumanMessage, AIMessage

load_dotenv()

model = ChatGroq(
    model="llama-3.3-70b-versatile",
    temperature=1.5,
)

chat_history = [
    SystemMessage(content="You are a helpful assistant that can answer questions and help with tasks.")
]

while True:
    user_input = input("You: ")
    if user_input.lower() == "exit":
        break

    chat_history.append(HumanMessage(content=user_input))
    result = model.invoke(chat_history)
    chat_history.append(AIMessage(content=result.content))
    print("Chatbot:", result.content)

print("Chat history:", chat_history)

Type exit to stop. The printed history shows every system, human, and AI turn.

ChatPromptTemplate

ChatPromptTemplate builds a list of chat messages from a template, with slots like {domain} and {input}.

from langchain_core.prompts import ChatPromptTemplate

chat_template = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant in a domain {domain} that can answer questions and help with tasks."),
    ("human", "{input}"),
])

prompt = chat_template.invoke({
    "domain": "healthcare",
    "input": "What is the capital of France?",
})
print(prompt)

The result is a structured chat prompt ready to send to a chat model.

MessagesPlaceholder

A MessagesPlaceholder sits inside a chat template. At run time it injects a list of past messages as dynamic chat history.

from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.messages import HumanMessage, AIMessage

chat_template = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant that can answer questions and help with tasks."),
    MessagesPlaceholder(variable_name="chat_history"),
    ("human", "{input}"),
])

chat_history = [
    HumanMessage(content="Hi"),
    AIMessage(content="Hello! How can I help?"),
]

prompt = chat_template.invoke({
    "chat_history": chat_history,
    "input": "What is the capital of France?",
})
print(prompt)

You can also load history from a file such as chat_history.json, then pass that list into chat_history when you invoke.

Day 24 takeaways

  • Temperature changes how fixed or creative the same prompt can feel.
  • Prompts guide model output. Text based prompts are what you use most.
  • Dynamic apps need templates, not only hard coded strings.
  • PromptTemplate and ChatPromptTemplate beat raw f strings for reuse and checks.
  • System, human, and AI messages plus MessagesPlaceholder power real chat history.
